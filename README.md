# sistema-bancario-concorrente
Sistema bancário concorrente desenvolvido em C utilizando threads, mutexes e semáforos para simular acesso simultâneo a recursos compartilhados. O projeto demonstra problemas clássicos de concorrência, como leitura suja, race conditions e inconsistências em buffers, através dos modelos Leitores × Escritores e Produtores × Consumidores.
